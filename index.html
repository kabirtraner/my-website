Terraform IaC Architecture

What is state locking and why is it important?

If supported by your backend, Terraform will lock your state file for all operations that could write state. This prevents concurrent runs from corrupting data. 
terraform {
  backend "azurerm" {
    container_name = "tfstate"
    key            = "prod.terraform.tfstate"
  }
}

Azure Core Infrastructure

What are Azure Availability Zones?

Availability Zones are physically separate datacenters within an Azure region. Each zone is made up of one or more datacenters equipped with independent power, cooling, and networking.

Azure DevOps (CI/CD)

What is the difference between Service Connections and Agent Pools?

Service connections store credentials securely to allow pipelines to connect to external endpoints (like Azure or GitHub). Agent pools represent the compute infrastructure execution context that builds the job.

Docker Mechanics

How can we reduce Docker image size?

Use multi-stage builds, clean up temporary dependencies in the same layers they were created, choose minimal bases like Alpine or Distroless, and leverage .dockerignore files.

Kubernetes Systems

What is a Pod inside Kubernetes?

A Pod is the smallest deployable computing unit you can create and manage in Kubernetes. It represents a single running instance of a process and can share network and storage spaces.

Git Workflows

What is the difference between git fetch and git pull?

git fetch downloads remote commits, tags, and files without modifying your local branch state. git pull triggers a fetch operation and instantly merges it into your active branch.

Azure Monitor & Observability

What are Log Analytics Workspaces?

A Log Analytics Workspace is a unique environment for Azure Monitor log data storage. It parses unstructured telemetry logs into analytical tabular schemas queried using Kusto Query Language (KQL).

Linux Systems Engineering

What are hard links vs symbolic links?

A hard link points directly to the physical inode data sector on storage blocks. A symbolic (soft) link serves as a shortcut string pointing to an existing file name address path.

Behavioral & HR Strategies

How do you manage a severe production outage?

First, isolate and mitigate to restore uptime (rollback deployment, scale clusters), communicate clearly via status dashboards, and then run a post-mortem to prevent recurrence.

Miscellaneous Topics

What is the core concept behind GitOps?

GitOps uses Git repositories as the single source of truth for infrastructure definitions. Tools like ArgoCD or Flux automatically synchronize your cluster state to match the code in Git.

FinOps & Cost Management

How do you optimize cloud compute costs safely?

Implement horizontal cluster autoscaling, delete unattached block storage volumes, use spot instances for non-production tests, and purchase savings plans for baseline operations.
