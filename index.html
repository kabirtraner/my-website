Terraform Core Architecture

What is the purpose of Terraform State?

Terraform records information about real-world infrastructure properties inside a state file (`terraform.tfstate`). This mechanism serves as a single source of truth mapping your remote cloud resource blueprints directly back onto configuration definitions.

How do you lock infrastructure configuration updates?

Concurrently applied state shifts are systematically locked through native API backends (like AWS DynamoDB or Azure Blob Storage lease maps) to fully avoid branch deployment drifts or resource corruption conflicts. 
terraform {
  backend "azurerm" {
    resource_group_name  = "remote-state-rg"
    storage_account_name = "tfstatestorageacct"
    container_name       = "corestate"
    key                  = "prod.terraform.tfstate"
  }
}

Azure Core Cloud Systems

Explain Availability Sets vs Availability Zones inside Azure.

Availability Sets protect applications against localized hardware disruptions within a single datacenter (Fault and Update domains). Availability Zones protect against an entire data center failure by placing instances across completely unique, physically isolated facility groups.

Azure DevOps Pipeline Systems

What is the core difference between Microsoft-Hosted and Self-Hosted CI Agents?

Microsoft-hosted agents run on clean, cloud-provisioned virtual machine instances that are completely destroyed post-execution. Self-hosted agents give you deep machine hardware control, allowing localized caching systems to reduce overall compile intervals.

Docker & Container Mechanics

How do Multi-Stage builds enhance container delivery lifecycles?

By discarding runtime dependencies, bulky source compilers, and temporary development code modules inside primary layer steps, you preserve only production binaries inside clean downstream deployments. This radically decreases overall images footprints.

Kubernetes Cluster Architecture

What happens when a Pod fails its Liveness probe vs Readiness probe?

If a Liveness Probe fails, the kubelet kills the container and initiates a target restart event loop. If a Readiness Probe fails, the control plane leaves the container intact but isolates the container from all active service end-points to block public client load drops.

Git Version Control Workflows

Explain the fundamental difference between Git Merge and Git Rebase.

git merge ties divergent branch histories together with a brand new tracking commit. git rebase rewrites commits onto the tip of the destination target branch, creating a completely linear history.
